# 实验室设备使用与借用规范

> 适用范围：格物实验中心全部实验室设备
> 更新日期：2026-11-14

## 一、设备分类

| 类别 | 设备 | 风险等级 | 使用要求 |
| --- | --- | --- | --- |
| 计算类 | GPU 服务器、深度学习工作站、高性能 PC、云终端、一体机 | 低 | 培训后使用，按预约机位 |
| 网络与机房类 | 服务器机柜、交换机 | 中 | 仅管理员操作，学生不得插拔 |
| 机械类 | 六轴机械臂、移动机器人 | 高 | 培训 + 双人作业 + 急停确认 |
| 高温类 | 3D 打印机 | 中 | 通风、防烫、不得无人值守 |
| 演示类 | 投影设备、音响 | 低 | 借用登记，用后归还 |

## 二、使用前

1. 在系统中查看设备状态：只有「正常」设备可预约；「维护中」设备不得使用。
2. 确认设备属于目标实验室，跨实验室设备不能带入使用。
3. 检查配件、线缆、耗材是否齐全，发现缺失或破损先报告管理员。
4. 首次使用某类设备，须完成对应培训并在预约时注明。

## 三、使用中

- 严格按操作说明使用，不得改变设备初始设置，不得私自拆装、改装。
- 机械类设备运行时人员不得离开；高温类设备运行时保持通风与看护。
- 设备出现异响、异味、过热、报警，立即停止使用并切断电源，报告管理员。
- 不得将设备、配件、耗材带出实验室；不得私自借给其他实验室或校外人员。

## 四、使用后

- 关闭设备电源，整理线缆与配件，按原位置归位。
- 在设备使用登记表中记录使用时间、使用人、设备状态与异常情况。
- 3D 打印需清理平台与废料；机械臂需回到安全位姿；云终端需退出登录。

## 五、借用与赔偿

- 投影、音响、移动存储等可借用设备，须在管理员处登记借用人与归还时间。
- 借用设备应在当天归还；逾期未还的，暂停借用资格。
- 正常使用造成的自然损耗不承担责任；违规操作、私自拆装、丢失造成的损坏，按学校设备管理规定赔偿。
- 发现设备损坏隐瞒不报的，按违规处理并追究责任。

## 六、维护与报修

- 管理员定期巡检设备，标注「维护中」的设备会在系统中同步状态。
- 学生发现故障应填写报修信息（设备名称、位置、现象、发生时间），不要自行处理。
- 维护完成后由管理员恢复设备状态，学生可重新预约。
