## 写作约定

- 每篇文档以一级标题开头，正文用二级/三级标题分节；每节尽量自包含，避免依赖上下文代词。
- 表格整块保留（切分时不拆表格）；列表项保持短句。
- 数字与规则必须与系统实现一致：30 分钟粒度、30 分钟–4 小时、12 小时取消线、各实验室容量与开放时间。
- 不写真实手机号、身份证号等个人信息；联系方式统一写「以公示牌与系统公告为准」。

## 更新流程

1. 修改或新增 `.md` 文档；
2. 重新执行知识库索引脚本（待实现）；
3. 在对话中抽查 3–5 个问题，确认检索命中与引用正确。
