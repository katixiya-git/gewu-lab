# 软件工程实验室使用指南

> 位置：实验楼 B302　容纳人数：50 人　开放时间：周一至周五 08:00–22:30
> 适用对象：软件工程、计算机科学与技术相关课程学生及项目团队
> 更新日期：2026-11-14

## 一、实验室定位

软件工程实验室承担程序设计、软件工程、Web 开发、数据库课程设计等教学任务，配备一体机与投影设备，适合小组讨论、项目开发与技术分享。

## 二、设备清单

| 设备 | 型号 | 数量 | 说明 |
| --- | --- | --- | --- |
| 一体机 | i7 / 32G | 50 台 | 学生开发终端 |
| 投影设备 | Epson CB-700U | 2 台 | 技术分享、答辩演示 |

## 三、预约要求

- 开放时间为周一至周五 08:00–22:30，需提前预约并通过审核。
- 小组预约须在用途中注明项目名称与人数，便于管理员安排机位。
- 班级统一上课由任课教师统一申请，不占用个人预约名额。
- 单次预约最长 4 小时；项目冲刺可申请连续时段，但需管理员确认。

## 四、使用规范

1. 按预约机位使用，不得随意搬动或调换机器；设备故障及时报告，不得自行拆修。
2. 不得在一体机上安装来源不明的软件，不得关闭杀毒软件与系统更新。
3. 项目代码建议使用 Git 托管，个人数据自行备份；离场前提交并推送代码。
4. 技术分享、答辩演示需提前调试投影与音响设备，使用后恢复原状。
5. 实验室内不得进行与项目无关的娱乐活动，不得大声喧哗影响他人。

## 五、环境与卫生

- 禁止在实验室内饮食，不得将饮料放在设备旁。
- 桌面保持整洁，线缆不得横穿通道；离开时将椅子归位、垃圾带走。
- 最后离开的同学负责关闭投影、照明与空调，并检查门窗。

## 六、离场检查

退出登录、关闭一体机，确认代码已提交、个人存储设备已带走；关闭公共设备电源后离开。
